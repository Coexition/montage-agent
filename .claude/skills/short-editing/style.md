# Style du créateur

> Mémoire durable du monteur IA. Lu avant chaque montage, mis à jour après chaque feedback qui exprime une préférence.
> Les valeurs chiffrées (couleurs, tailles, rythme) sont dans `style.json`.

## Look
- Fond clair crème (`#f4f2ee`) pour les écrans de motion design, caméra en split en bas.
- Typo : Inter Display Black pour les titres et chiffres, Inter pour le reste.
- Accent bleu (`#2f7bff`) pour les mots-clés, jaune (`#ffd400`) pour le mot prononcé dans les sous-titres.
- Cartes / badges arrondis (radius 36), ombre douce.
- Vrais logos des outils cités (jamais de faux logo).

## Rythme
- Cuts très agressifs : chaque silence supprimé, "euh" supprimés.
- Vitesse ×1.1 par défaut.
- Un changement visuel toutes les ~2,5 s maximum.
- Punch-in alterné (×1.1) à chaque jump-cut quand la caméra est plein écran.

## Footage
- Caméra plein écran pour le hook et les punchlines, split (caméra en bas) pendant les explications/chiffres.
- B-roll / captures d'écran quand on parle d'un outil.

## Préférences
- Chiffres → compteur animé géant, avec unité en accent.
- Comparaisons → barres horizontales animées, le gagnant en accent.
- Pas de sablier / icônes génériques : préférer une vraie interface (fenêtre de rendu, barre de progression, chrono).
- CTA final : texte + flèche vers le bas.
